## Самостоятельные доработки проекта (Высокий уровень на 5 баллов):

### Раздел 1. Визуальный интерфейс и интерактивность (UI/UX)
1. **Интерактивный блок отзывов:** На главную страницу внедрен полноценный раздел отзывов покупателей со стилизованными карточками, оценками-звездами, цитатами и аватарами пользователей.
2. **Эффект 3D-приподнимания (Продвинутый Hover-эффект):** Для карточек товаров настроена отзывчивая плавная анимация `transform: translateY(-8px)` и динамическое появление глубокой тени бренда при наведении курсора.
3. **Эффект размытия заднего плана (Glassmorphism):** Нативное модальное окно `<dialog>` доработано через псевдоэлемент `::backdrop` с использованием размытия `backdrop-filter: blur(5px)` для концентрации внимания на форме.
4. **Цветовая кодировка статусов (Бейджи):** Бейджи товаров разделены по визуальному смыслу и цветам (Оранжевый — Хит, Красный — Скидка, Зелёный — Новинка) для улучшения навигации.

### Раздел 2. Структура вёрстки и архитектура кода
5. **Расширение ассортимента каталога:** В сетку товаров добавлена 4-я карточка товара (Nike Air Force 1) с уникальным контентом для проверки масштабируемости Grid-сетки.
6. **Улучшение навигационной структуры:** Вместо единого шаблона реализована архитектура выделенных страниц под конкретные бренды (`product-nike.html`, `product-adidas.html`).
7. **Повышение доступности (Accessibility):** Внедрена система «умного фокуса» через селекторы `:focus-visible` и интерактивная подсветка ошибок валидации через атрибут `aria-invalid="true"`.
8. **Чистая организация CSS-классов:** Проведена стопроцентная очистка HTML-документов от инлайн-стилей `style="..."`, все свойства вынесены в БЭМ-структуру стилей.


В проекте используются современные подходы к стилизации:
* **CSS-переменные в `:root`**: все цвета, отступы и скругления вынесены в глобальные переменные для удобства масштабирования.
* **Единая шкала отступов (`--space-*`)** и скруглений (`--radius-*`).
* **Интерактивные состояния**: для ссылок, кнопок и полей настроены псевдоклассы `:hover`, `:focus-visible`, и `:disabled`.
* **Доступность (Accessibility)**: фокус при навигации с клавиатуры (клавиша `Tab`) сделан явно видимым с помощью `:focus-visible`.
* **Валидация**: ошибочные поля визуально подсвечиваются через селектор атрибута `[aria-invalid="true"]`.
* **Структурированный код**: файл `css/style.css` разбит комментариями на логические блоки.
