## Использованные технологии и доработки (на 5 баллов):
1. **CSS-архитектура и БЭМ**: код разбит на логические секции, именование классов выполнено строго по методологии БЭМ (Блок-Элемент-Модификатор).
2. **Дизайн-система**: все ключевые цвета, шрифты, радиусы скруглений и шкала отступов вынесены в глобальные переменные `:root`.
3. **CSS Grid**: сетка каталога реализована на гридах с использованием адаптивной декларации `repeat(auto-fill, minmax(250px, 1fr))`.
4. **Интерфейсные состояния**: настроены плавные переходы (`transition`), интерактивные ховеры (`:hover`) и доступный фокус с клавиатуры (`:focus-visible`).
5. **Фиксация и позиционирование (Position)**:
   * Реализована **липкая фиксация (`position: sticky`)** для боковой панели фильтров.
   * Реализована **абсолютная фиксация (`position: fixed`)** для круглой кнопки возврата «Наверх».
6. **Доступность (Accessibility)**: все поля ввода (`input`) жестко связаны со своими текстовыми подписями (`label`) через валидные атрибуты `id` и `for`.

В проекте используются современные подходы к стилизации:
* **CSS-переменные в `:root`**: все цвета, отступы и скругления вынесены в глобальные переменные для удобства масштабирования.
* **Единая шкала отступов (`--space-*`)** и скруглений (`--radius-*`).
* **Интерактивные состояния**: для ссылок, кнопок и полей настроены псевдоклассы `:hover`, `:focus-visible`, и `:disabled`.
* **Доступность (Accessibility)**: фокус при навигации с клавиатуры (клавиша `Tab`) сделан явно видимым с помощью `:focus-visible`.
* **Валидация**: ошибочные поля визуально подсвечиваются через селектор атрибута `[aria-invalid="true"]`.
* **Структурированный код**: файл `css/style.css` разбит комментариями на логические блоки.
